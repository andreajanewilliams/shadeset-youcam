# LookKit

Complete application source, assets, tests and deployment configuration are in **lookkit-source.zip**. Download and extract it, then run:

```sh
cd lookkit
npm ci
npm test
npm run dev
```

Open http://127.0.0.1:5173. Node.js 20.9+ is required. The saved sample needs no API key. Full setup, daily API limits and limitations are documented in the included README.md.
